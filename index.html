IoT Lab - Alertas

Projeto experimental de monitoramento de sensores, registro de telemetria e notificações sobre eventos que exigem atenção.

O que o projeto faz?

O protótipo atual acompanha leituras de um sensor de umidade instalado em um vaso de plantas. As medições são enviadas para um servidor que registra o histórico, apresenta um painel de acompanhamento e está sendo preparado para emitir alertas, como necessidade de verificar a rega, falha de sensor e interrupção de comunicação.

O envio automático de e-mails está em desenvolvimento. O projeto não oferece atualmente um serviço comercial de monitoramento e não aciona bombas de irrigação automaticamente.

Para que utilizamos o acesso ao Google?

O aplicativo IoT Lab - Alertas solicita a permissão gmail.send para enviar e-mails operacionais por meio de uma conta Google autorizada. Não solicita permissão para ler, modificar ou excluir e-mails da conta.

A autorização é usada exclusivamente para o envio de notificações relacionadas ao monitoramento. Para conhecer o tratamento de dados e as opções de revogação, consulte nossa política de privacidade.
