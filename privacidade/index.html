Política de Privacidade

IoT Lab - Alertas · 20 de outubro de 2026

Esta política descreve o tratamento de dados no projeto experimental IoT Lab - Alertas.

1. Dados utilizados

Registramos dados técnicos de sensores, horários e eventos de monitoramento. Para enviar notificações, utilizamos o endereço de e-mail do destinatário e o conteúdo do alerta.

2. Finalidade e acesso ao Google

Os dados servem para acompanhar o funcionamento dos sensores e avisar sobre condições que exigem atenção. A integração com a Gmail API solicita exclusivamente gmail.send, para enviar e-mails pela conta autorizada; não solicita leitura, alteração ou exclusão da caixa postal. Não vendemos dados pessoais nem os utilizamos para publicidade.

3. Armazenamento e segurança

Os registros técnicos são mantidos no servidor do laboratório enquanto necessários a testes e diagnósticos. As credenciais OAuth devem ser armazenadas de forma privada, fora de repositórios públicos. Os alertas são enviados aos destinatários configurados por meio dos serviços do Google. O uso de dados das APIs Google observará a Política de Dados do Usuário dos Serviços de API do Google, inclusive seus requisitos de uso limitado.

4. Revogação e exclusão

O acesso do aplicativo à conta Google pode ser revogado em Conexões de terceiros. A revogação interrompe a autorização de envio, mas não remove automaticamente registros já armazenados. Solicitações de acesso, esclarecimento ou exclusão de dados podem ser feitas pelo contato abaixo.

5. Contato e atualizações

iotlabalertas@gmail.com. Esta política poderá ser atualizada conforme o projeto evoluir.
